What's new?

Hello everyone! I was able to get some free time to work on the website. I decided to add some important info related to items and skills as well as make minor quality of life improvements.

Version 2.3.0 Update

  • Damage Calculator: Optimized the page performance and added the UUBL tier.
  • QOL: Added option for the "Copy to Clipboard" feature (copy wheel image).
  • Database: Separated Torituki, Skill Config, and Moves into independent categories; added skill info for equipment and an Effect info list for skills.
  • Visual & Text Fixes: Refreshed overall UI layouts, updated seasonal December banners, and fixed text encoding for Yo-kai descriptions.
  • Modular UI & Styling: Restructured site-wide CSS into clean, modular files for some pages, refreshing the overall UI layout.
I might add more features in the future, depending on what you would like to see next. This website is focused on creating tools and providing information to players. However, if you're interested in other features like RAM editing, feel free to message me! I might add them in the next update if they aren't too complicated to code. Hope all of you will have a great day! Below you can see all content that was added previously. If you have any questions, you can contact me through my discord: @hilwin
