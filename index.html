What's new?

Hello everyone! I'm back with another update for the website. I've just rolled out **Version 2.4.1** to deploy some quick bug fixes right after our major **2.4.0** release. This time, I focused on adding highly requested language options, cleaning up the code behind the scenes, and making the site faster and smoother.

Version (Undefined) Update

  • Localization: Added initial Japanese language support for Yo-kai names and descriptions on the Medallium and Yo-kai Info pages.
  • Database: Added new, dedicated text database for Japanese Yo-kai text as well as text package for future language options.
  • Performance: Restructured and optimized the CSS layout, removing redundant properties to significantly improve page loading speeds.
  • Code Refactoring: Moved main global styling properties over to centralized root variables, making the codebase much cleaner and easier to maintain.
I might add more features in the future, depending on what you would like to see next. This website is focused on creating tools and providing information to players. However, if you're interested in other features like RAM editing, feel free to message me! I might add them in the next update if they aren't too complicated to code. Hope all of you will have a great day! Below you can see all content that was added previously. If you have any questions, you can contact me through my discord: @hilwin
