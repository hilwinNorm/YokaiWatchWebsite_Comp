What's new?

Hey y'all! I'm way busier this month than previously, though I've still decided to add some minor content to the website after getting some requests.

Version 2.6.0 Update

  • Sidebar Design: Changed the sidebar section close button to a brand new design.
  • Elemental Resistance: Moved the elemental resistance list to the top of the page for better visibility.
  • Attitude Database: Updated and changed the underlying values stored in the attitude database.
  • Stat Values: Refactored value calculations to floor stat values inside elements within the list.
  • Team Builder UI: Redesigned the team builder page to make it significantly more user-friendly.
I might add more features in the future, depending on what you would like to see next. This website is focused on creating tools and providing information to players. However, if you're interested in other features like RAM editing, feel free to message me! I might add them in the next update if they aren't too complicated to code. Hope all of you will have a great day! Below you can see all content that was added previously. If you have any questions, you can contact me through my discord: @hilwin
