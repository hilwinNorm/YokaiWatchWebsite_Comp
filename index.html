What's new?

Hey y'all! I'm way busier this month than previously, though I've still decided to add some minor content to the website after getting some requests.

Version 2.5.0 Update

  • Added move button to team builder (v2.5.0): You can switch selected 2 yo-kai medals on your team by pressing on first one and then the second you want to swap.
  • New search options: Added advanced search feature that currently works only at medallium page (also at team builder and damage calculator v2.5.1) and added option to search by tribe on soul gem page.
  • How to use advanced feature: First write the yo-kai stat you want to compare, then the operator for comparison and then write the value you want to compare yo-kai stat to. Your search term should match this pattern: [HP/STR/...][/>=/...][0...999]
  • Updated tiers(v2.5.0): Changed Slurpent from UUBL to OU, moved Drizdella from UU to OU.
  • Improved CSS: Created new global classes for list pages.
  • Bug patches(v2.5.1): Fixed search function not working on some pages.
I might add more features in the future, depending on what you would like to see next. This website is focused on creating tools and providing information to players. However, if you're interested in other features like RAM editing, feel free to message me! I might add them in the next update if they aren't too complicated to code. Hope all of you will have a great day! Below you can see all content that was added previously. If you have any questions, you can contact me through my discord: @hilwin
